# Contributing

Install the project with the dev extra and run `python -m pytest -q`.
Keep geometry, ranking, UI, and visualization separate.

New catalog entries need a unique stable ID, supported shape/texture labels,
length, daily maintenance, explanatory text, and preview parameters.
Document whether a change is heuristic or learned and include meaningful tests.
Never commit personal photos, model binaries, secrets, or scraped datasets.
Describe provenance and consent for any proposed dataset; do not claim evaluation
results without a reproducible experiment.
